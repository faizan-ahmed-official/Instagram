# Instagram
Instagram frontend clone built using C++ and Qt Widgets, with CMake for project management. Each widget has separate header and implementation files for better code organization. SQLite is integrated to store and manage post-related data.

## Features
Instagram frontend include:
1. Header.
2. Story Section.
3. Feed Section.
4. Switching panel.

## Technology Stack
1. C++ 17
2. Qt6
2. CMake 3.16

## How To Contribute 
1. Fork the repository to your GitHub account.
2. Clone your fork and make the desired changes or add new features.
3. Submit a Pull Request (PR) so I can review and approve your changes for the frontend.

## How To Build
1. Clone the repository to your local machine.
2. Build and run.
