# Instagram
Instagram frontend clone built using C++ and Qt Widgets, with CMake for project management. Each widget has separate header and implementation files for better code organization. SQLite is integrated to store and manage post-related data.

## Features
Instagram frontend include:
1. Header.
2. Story Section.
3. Feed Section.
4. Switching panel.

## Technology Stack
1. C++ 17
2. Qt6
2. CMake 3.16
